# wex-pan

Wex（newwex）TVBox 配置的**纯网盘版**：从原配置 100 个站点中只保留网盘仓，删除普通影视采集/秒播站、直播站与顶层直播源（lives），其余配置（spider、wallpaper、parses、doh、rules、ads、headers）原样保留。

- 保留 30 个站点：配置中心、我的网盘、豆瓣首页、网盘 4K 站 17 个（花卷/玩偶/观影/七味/盘库/虎斑/木偶/多多/快影/蜡笔/闪电/剧透/立播/原盘/蜗牛/盘迷/逸动）、115 分享、Alist、WebDav、盘搜 5 个、推送
- 源文件：https://9280.kstore.vip/newwex.json （2026-11-06 裁剪；原配置本身无磁力站）
